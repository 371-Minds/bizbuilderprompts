# Specifics-forcing AI prompt

> **Goal:** Get useful AI drafts instead of generic slop by demanding exact audience, length, structure counts, and constraints up front.
> **Framework:** custom
> **Tags:** ai-prompts, copywriting, specificity

---

## Methodology

Build the request as a specificity checklist — every slot pinned to a number or a named audience:

1. Name the audience and the topic.
2. Pin the length (e.g., 150 words).
3. Pin the structure with counts (e.g., 3 causes, 2 quick fixes, 1 metric to watch).
4. Constrain the closing (e.g., a 12-word CTA).
5. [extension] Add tone ("friendly and direct"), exclusions ("avoid fluff and vague claims"), and one actionable next step.

## Worked example (from the source)

> Write a 150 word intro for busy ecommerce founders about "reducing cart abandonment", include 3 causes, 2 quick fixes, 1 metric to watch, and a 12 word CTA.
