# Start with one reader problem

> **Goal:** Write a piece that feels made for one person by anchoring it to a single painful problem.
> **Framework:** custom
> **Tags:** content-strategy, audience, copywriting, focus

---

## Methodology

1. Pick one painful problem your reader wants solved today. 2. Write a one-line promise of the result you will deliver. 3. Teach the steps in order, making every tip support that one promise. 4. Cut anything that drifts to another problem. 5. Reuse the same problem to sharpen email subject lines, offers, and sales calls.
